# nil-3b Engine

Sovereign, offline-first 3B parameter AI model engineered for extreme edge quantization and zero-bandwidth environments across Africa.

Developed by **Nion Technologies, Inc.**

## Technical Specifications
- **Model Size:** 1.8GB (GGUF `q4_k_m`)
- **Inference Speed:** 38ms local latency
- **Memory Allocation:** <120MB RAM operational footprint
- **Localization:** Fine-tuned on 32 African languages and regional dialects
- **Target Hardware:** ARM Cortex-A72, wearable microcontrollers, consumer laptops
